# Frontend Angular

O frontend é uma aplicação Angular standalone. As telas e os controles ficam
em `src/app`; o motor TypeScript e a persistência local do ranking ficam em
`src/app/game`.

Os comandos de desenvolvimento, build e teste são executados na raiz do
repositório. Consulte o [README principal](../../README.md) para instruções de
instalação, execução local e publicação.
